# Interior Designer & All Work

## 📌 Project Overview

Interior Designer & All Work is a modern, responsive, and user-friendly interior design website developed using React.js and Tailwind CSS.

The website provides information about interior design services, home renovation, furniture design, painting, false ceiling, electrical work, plumbing, and other home improvement solutions.

It is designed with a clean and professional user interface to help users explore different services and connect with the team for their interior design requirements.

## ✨ Features

### 1. Home Page
- Modern and attractive hero section.
- Professional interior design presentation.
- Featured services and project highlights.
- Call-to-action buttons for customer inquiries.

### 2. About Page
- Information about the company.
- Introduction to interior design services.
- Professional and clean layout.

### 3. Services Page
- Displays available interior design services.
- Easy navigation to individual service pages.
- Organized service categories.

### 4. All Work Section
The All Work section provides different categories of interior and home improvement services.

- POP Work
- Painting Work
- Electrical Work
- Furniture Work
- Plumbing Work
- False Ceiling
- Glass & Aluminum Work
- Renovation Work
- Wall Design
- Wallpaper Design

### 5. Portfolio Page
- Showcases interior design projects.
- Displays creative design ideas.
- Helps users explore different interior styles.

### 6. Contact Page
- Contact information.
- Customer inquiry section.
- WhatsApp integration for direct communication.

### 7. Responsive Design
- Mobile-friendly layout.
- Tablet and desktop support.
- Responsive navigation and content sections.

### 8. Navigation
- React Router DOM for page navigation.
- Navbar with dropdown menu.
- Easy navigation between different pages.

## ⚙️ Installation and Setup

### Prerequisites

Before running the project, make sure you have installed:

- Node.js
- npm
- Visual Studio Code
- Git

### Step 1: Clone the Repository

```bash
git clone https://github.com/RISHABH125523/Interior_Designer-_-_-ALL.git
```

### Step 2: Navigate to the Project Folder

```bash
cd Interior_Designer-_-_-ALL
```

### Step 3: Install Dependencies

```bash
npm install
```

This command installs all required project dependencies.

### Step 4: Start the Development Server

```bash
npm run dev
```

### Step 5: Open the Website

Open the local URL shown in your terminal, usually:

```text
http://localhost:5173
```

The website will run in your browser.

## 🚀 How to Use the Website

1. Open the website in your browser.
2. Explore the Home page to view the interior design introduction.
3. Visit the About page to learn about the company.
4. Open the Services page to explore available services.
5. Use the All Work dropdown to navigate to different work categories.
6. Visit the Portfolio page to explore interior design projects.
7. Open the Contact page to get in touch.
8. Use the WhatsApp button to contact the team directly.
